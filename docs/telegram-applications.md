# Заявки на практику в Telegram

Новые заявки на практику не сохраняются в базе сайта. Сервер отправляет их
через Telegram-бота и сообщает пользователю об успехе только после подтверждения
Telegram.

## Создание бота

1. Откройте в Telegram `@BotFather`.
2. Отправьте команду `/newbot`.
3. Задайте имя и username бота.
4. Сохраните выданный токен.
5. Откройте созданного бота и нажмите **Start**.

## Получение chat_id личного чата

1. После нажатия **Start** отправьте боту любое сообщение.
2. Откройте в браузере:

   `https://api.telegram.org/bot<ТОКЕН>/getUpdates`

3. Найдите фрагмент `"chat":{"id":...}`. Число в поле `id` и есть
   `TELEGRAM_CHAT_ID`.

Альтернативный способ: написать боту `@userinfobot`, который покажет ID личного
аккаунта.

## Приватная группа или канал

Добавьте созданного бота в приватную группу или канал. Для канала назначьте его
администратором с правом публикации сообщений. После этого отправьте сообщение
в группу/канал и снова вызовите `getUpdates`. ID групп и каналов обычно
отрицательный и часто начинается с `-100`.

## Настройка Render

В сервисе Render откройте:

`Environment` -> `Environment Variables`

Добавьте:

- `TELEGRAM_BOT_TOKEN` — токен, полученный у BotFather;
- `TELEGRAM_CHAT_ID` — ID личного чата, группы или канала.

Сохраните переменные и выполните повторный deploy. Токен нельзя добавлять в
GitHub, исходный код или публичные файлы сайта.
